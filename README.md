# 聚餐分帳器

繁體中文、可離線使用的聚餐分帳網頁，手機與電腦都能操作。

## 使用方式

用瀏覽器開啟 [線上分帳器](https://manman30km.github.io/bill-splitter/)，或下載本作品後開啟 `index.html`，輸入未加服務費的總金額與人數，再選擇是否加 10% 服務費，按「計算分帳」。

- 人數包含付錢的人。
- 金額以整數元顯示；服務費四捨五入到整數元。
- 除不盡的零頭由付錢的人負擔，畫面會標示零頭並核對總額。
- 不需連網、不需登入、不儲存任何人的資料。

## 範例

3 個人、1,000 元、不加服務費：付錢的人 334 元，其他人各 333 元，合計 1,000 元。
